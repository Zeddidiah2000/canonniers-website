## Step 1 — Generate a new PHOTO_UPLOAD_TOKEN

Run this in the terminal to generate a secure random hex token:

```
! node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"
```

Copy the output. This is your new `PHOTO_UPLOAD_TOKEN`. Keep it in this chat — you'll use it in Steps 2 and 3.

---

## Step 2 — Set the new PHOTO_UPLOAD_TOKEN on the worker

```
! cd "C:\Users\Potato\Documents\Canonniers Website\photo-worker" && npx wrangler secret put PHOTO_UPLOAD_TOKEN
```

Paste the token from Step 1 when prompted. Wrangler will confirm: `✔ Success! Uploaded secret PHOTO_UPLOAD_TOKEN`.

---

## Step 3 — Update the hardcoded token in admin-photos.html

Read `repo-working/admin-photos.html` and find this line:

```js
const PHOTO_TOKEN = '09b9cbaec0cbcbda115b5da25ac0ce7844e82ab8f09b49b7';
```

Replace the value with the new token from Step 1. Then commit and push:

```
git add admin-photos.html
git commit -m "rotate PHOTO_UPLOAD_TOKEN"
git push
```

## Step 4 — Rotate CF_IMAGES_TOKEN in the Cloudflare dashboard

This token is a Cloudflare API token (not a random hex string — it must be generated by Cloudflare).

1. Go to: **Cloudflare dashboard → My Profile → API Tokens**
2. Find the token used for Cloudflare Images on the `canonniersdequebec.ca` account (it will have Images read/write permissions).
3. Click **Roll** (or **Edit → Roll**) to generate a new value.
4. Copy the new token value — Cloudflare only shows it once.
